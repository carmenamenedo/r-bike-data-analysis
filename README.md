# 🚲 Bike Traffic Data Analysis with R

Data analysis project developed in R using bicycle traffic data.

The project focuses on data cleaning, transformation, exploratory analysis and visualization using the Tidyverse ecosystem.

## 📌 Project Overview

The dataset contains daily bicycle counts from different counting locations throughout 2017.

The objective is to transform the original dataset into a tidy format and analyze bicycle traffic patterns across the different locations.

## 🛠️ Technologies & Libraries

- R
- R Markdown
- Tidyverse
- dplyr
- tidyr
- ggplot2
- lubridate
- stringr

## 🔍 Main Tasks

The project includes:

- Importing and exploring CSV data.
- Cleaning and restructuring the original dataset.
- Transforming data from wide to long format using `pivot_longer()`.
- Processing and extracting information from dates.
- Cleaning location names.
- Identifying and analyzing missing values.
- Calculating total bicycle traffic by location.
- Performing grouped data analysis.
- Creating data visualizations in R.

## 📂 Project Structure

- `amenedo_peñamaria_carmen.Rmd` → R Markdown source code and analysis.
